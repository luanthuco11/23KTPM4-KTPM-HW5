# Performance-test data

The CSV files in this directory are generated by `scripts/New-TestData.ps1` and are committed as required test artifacts.

| File | Intended use | Rows |
|---|---|---:|
| `users-load.csv` | Load test | 40 |
| `users-stress.csv` | Stress test | 250 |
| `users-spike-baseline.csv` | Spike baseline thread group | 20 |
| `users-spike-burst.csv` | Spike burst thread group | 150 |

Each row parameterizes credentials, product search, quantity, and shipping address. Product ID and price are deliberately not hard-coded: JMeter extracts them from the live product-search response so the workflow verifies correlation.

All accounts are synthetic local test accounts. They must be registered after every backend start because this SUT recreates its SQLite database at startup.
